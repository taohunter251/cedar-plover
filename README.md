# Three.js reconstruction miner

Image-to-Three.js generation pipeline for the 404-GEN GPT competition. Derived from bachptv-zenai/chronobreak (commit 8eaf8f69), itself derived from research-somthing-t/lumen-kit and golden217/sn17gen.

This build runs TuttiGenerator/solid-mango (commit 89bb574d, `sceneforge/` and `data/`) and then one refine of its result.
